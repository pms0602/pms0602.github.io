## 왜 기술 블로그를 만들었을까?

공부한 내용을 머릿속에만 두면 시간이 지난 뒤 다시 이해하기 어렵습니다. 그래서 배운 원리와 시행착오를 글로 남기기 위해 기술 블로그를 만들었습니다.

## GitHub Pages와 Jekyll

GitHub Pages는 GitHub 저장소에 있는 정적 파일을 웹사이트로 공개할 수 있는 호스팅 서비스입니다. Jekyll은 Markdown 게시글과 레이아웃을 HTML 페이지로 만들어 줍니다.

## 앞으로의 기록 방식

- 문제를 만난 상황과 원인을 먼저 적습니다.
- 해결 과정과 핵심 코드를 정리합니다.
- 참고한 공식 문서나 자료를 함께 남깁니다.

이 블로그가 결과만 모아 놓는 공간이 아니라, 이해에 도달하기까지의 과정도 담는 기록장이 되기를 바랍니다.
