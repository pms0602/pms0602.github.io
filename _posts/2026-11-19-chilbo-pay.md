# 칠보페이 - 학교 생활에 포인트 시스템을 도입하다

## 1. 프로젝트 소개

칠보페이는 수원칠보고등학교에서 사용한 교내 포인트 결제 시스템이다.

학생들의 교내 활동 참여를 장려하고 지속적인 동기를 부여하기 위해 기획한 서비스로, 특정 활동에 참여하면 포인트를 적립하고, 적립한 포인트를 학생회에서 준비한 간식이나 굿즈 등으로 교환할 수 있도록 개발했다.

단순히 포인트를 기록하는 것을 넘어 학생들의 활동과 실질적인 보상을 연결하는 교내 서비스를 만드는 것이 프로젝트의 목표였다.

## 2. 주요 기능

### ① QR 코드 기반 포인트 적립

학생들은 모바일 애플리케이션에서 자신의 QR 코드를 확인할 수 있다. 교내 활동에 참여한 학생이 운영진에게 QR 코드를 제시하면, 운영진이 이를 스캔하여 해당 학생에게 포인트를 지급하는 방식이다.

이를 통해 학생 정보를 일일이 검색하거나 수동으로 입력하는 과정을 줄이고, 포인트 지급 절차를 간소화했다.

### ② 포인트 확인 및 관리

학생들은 자신의 적립 포인트를 확인하고 관리할 수 있다. 이를 통해 현재 보유한 포인트와 활동에 따른 적립 현황을 확인할 수 있도록 했다.

### ③ 상품 교환

학생들이 적립한 포인트를 이용하여 학생회에서 준비한 간식이나 굿즈 등을 교환할 수 있도록 했다. 교내 활동 참여가 실제 보상으로 이어지는 구조를 구현했다.

### ④ 운영진 관리 기능

운영진이 학생들의 QR 코드를 인식하고 포인트를 지급하는 등 서비스 운영에 필요한 기능을 제공했다.

## 3. 개발 환경 및 배포

웹 서비스는 **Node.js**를 기반으로 개발했으며, 모바일 애플리케이션은 **Flutter**를 활용했다.

GitHub 저장소에는 서버 코드인 `app.js`, 프로젝트 의존성을 관리하는 `package.json`, 로그인 관련 `lib_login`, 세션 관련 `sessions`, 거래 내역과 관련된 `transaction.json` 등의 파일이 포함되어 있다.

웹 서비스 개발에 그치지 않고 Flutter를 이용해 모바일 애플리케이션으로 확장했으며, 최종적으로 **원스토어(ONE store)에 앱을 배포**했다.

이를 통해 웹 개발뿐만 아니라 모바일 애플리케이션 개발과 실제 앱 마켓 배포까지 경험할 수 있었다.

## 4. 프로젝트를 통해 얻은 경험

칠보페이는 개인적인 학습을 위한 프로젝트가 아니라 실제 학교 구성원들이 이용하는 서비스를 개발했다는 점에서 의미가 있었다.

서비스를 기획하고 구현하는 과정에서 학생과 운영진이라는 서로 다른 사용자의 입장을 고려해야 했으며, QR 코드를 활용한 포인트 지급 방식처럼 실제 운영 환경에서 필요한 기능을 고민할 수 있었다.

또한 Node.js 기반 웹 서비스와 Flutter 기반 모바일 애플리케이션을 함께 개발하면서 하나의 서비스를 여러 플랫폼으로 확장하는 경험을 쌓았다.

특히 웹 서비스의 기능을 모바일 애플리케이션으로 확장하고, 이를 실제 앱 마켓에 배포하는 과정은 개발한 결과물이 사용자에게 전달되기까지의 흐름을 이해하는 계기가 되었다.

## 5. 부족했던 점과 개선 방향

프로젝트를 돌아보았을 때 가장 아쉬웠던 부분은 **보안**이었다.

당시에는 서비스의 기능을 구현하고 정상적으로 작동시키는 데 집중했기 때문에 사용자 인증과 권한 관리, 데이터 무결성 등 보안 측면을 충분히 고려하지 못했다.

특히 포인트를 관리하는 서비스의 특성상 다음과 같은 보안 요소가 중요하다.

- **QR 코드 위변조 방지:** 다른 사용자의 QR 코드를 악용하거나 비정상적인 방식으로 포인트를 적립하는 행위 방지
- **중복 포인트 지급 방지:** 동일한 활동에 대해 포인트가 반복 지급되는 상황 방지
- **접근 제어:** 운영진과 일반 학생의 권한을 구분하고 비인가 사용자의 접근 제한
- **데이터 무결성:** 포인트 적립 및 사용 내역이 임의로 변경되거나 손실되지 않도록 관리

하지만 당시에는 이러한 요소들을 체계적으로 검증하고 대응하는 데 부족함이 있었다.

또한 기능 구현에 집중하면서 전체적인 시스템 구조와 데이터 흐름을 설계하는 역량, 예외 상황에 대비한 테스트 경험도 더 필요하다고 느꼈다.

이를 보완하기 위해 앞으로는 다음과 같은 부분을 중점적으로 학습하고자 한다.

- **웹 보안:** 인증과 인가, 세션 관리, 접근 제어, 주요 웹 취약점 분석 및 예방
- **백엔드 및 데이터베이스:** 데이터베이스 설계, 트랜잭션, 데이터 무결성 학습
- **시스템 설계:** 웹과 모바일 간 API 통신 및 전체적인 데이터 흐름 설계
- **테스트 및 유지보수:** 비정상적인 요청과 예외 상황을 고려한 테스트 역량 강화

## 6. 마무리

칠보페이는 학교라는 실제 환경에서 발생하는 문제를 발견하고 이를 웹과 모바일 서비스로 해결하고자 했던 프로젝트다.

서비스 기획부터 웹 개발, Flutter를 활용한 모바일 애플리케이션 개발, 원스토어 배포까지 경험하면서 하나의 서비스가 사용자에게 전달되기까지의 과정을 배울 수 있었다.

동시에 실제 서비스를 개발할 때는 기능 구현뿐만 아니라 보안과 안정성까지 함께 고려해야 한다는 점도 깨달았다.

이번 경험을 바탕으로 앞으로는 단순히 작동하는 서비스를 만드는 것을 넘어, 사용자가 신뢰하고 안전하게 이용할 수 있는 서비스를 개발하는 역량을 갖추고자 한다.
