## 요약보다 구조를 남기기

좋은 기술 노트는 문서의 문장을 그대로 옮긴 것이 아니라, 나중에 다시 봤을 때 개념과 사용 맥락을 떠올릴 수 있도록 정리한 기록입니다.

## 추천하는 구성

1. **문제:** 어떤 상황에서 이 개념이 필요한가?
2. **핵심 개념:** 무엇이며 어떤 원리로 동작하는가?
3. **예시:** 짧은 코드나 구체적인 상황에서 어떻게 쓰이는가?
4. **주의점:** 흔한 실수나 한계는 무엇인가?
5. **출처:** 공식 문서와 추가로 읽을 자료는 무엇인가?

## Markdown 예시

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("world"))
```

코드에는 동작 결과뿐 아니라 중요한 줄이 왜 필요한지도 함께 설명하면 좋습니다.
